Blocks are numbered from the bottom, so y 0 is the lowest row. Rows 16 to 27 are empty except the tall wall at x 171, so this view stops at row 15.

Rows of snacks

Each snack sits in the middle of one block, so a row of snacks close together is a row of neighbouring blocks. One line of script does it: row cheezie x=17..20 y=7 is four cheezies on blocks 17, 18, 19 and 20. Add by=3 to leave gaps. Choose a row to see it in the level.

A mismatch to know about The real language counts y up from the bottom, so ground is a low number and the sky is a high one, as on this page. The prototype's small sample level counts rows from the top, so its script shows different numbers for the same picture, and that sample is not a real level. The walkthrough's paint demo now counts from the bottom like real scripts. Making the prototype load this real level, with the same numbering, is the fix.
