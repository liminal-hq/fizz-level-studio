A builder language for levels

Today a level is a Rust function of Builder calls. This keeps that shape, with names instead of constants and ranges instead of paired numbers, so the editor, Claude and a person can all read and write the same text.

crater.fizz — a sketch, not a spec
level "Crater Fields" 192x28 ground=4
theme crater   area crater-fields
start 3,4

terrain
  flat 14, up 2, flat 6, down 2, flat 5
  pool 4, flat 8, up22 2, flat 10, gap 3
  // ...
walls

blocks
  block      x=49..51 y=10
  red-door   x=171    y=6..7
  exit       x=186    y=6..7

treats
  soda       x=36 y=5
  cookie     x=50 y=11

enemies
  gloop      x=35, 62, 85
  drone      x=88.5 y=7.5
  crystal    x=10, 26, 60, 98

edits   // painted in the studio, by you or Claude
  paint one-way  x=26,28,30 y=9
  paint cheezie  x=26,28,30 y=8
