# @liminal-hq/fizz-studio-protocol

TypeScript types generated by `ts-rs` from the Rust wire types in `crates/fizz-studio-protocol` (and, later, from the domain plugins' own types). The frontend imports them from `@liminal-hq/fizz-studio-protocol/generated/<Type>`. Never edit a file in `src/generated/` by hand: run `bun run bindings` after changing a Rust type, and `bun run check:bindings` fails when the committed files are out of date.
