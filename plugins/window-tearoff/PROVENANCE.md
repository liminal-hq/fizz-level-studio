# Provenance

This plugin is a copy of `plugins/window-tearoff` from [liminal-hq/waypoint](https://github.com/liminal-hq/waypoint), taken at commit `a3c9894728da69a9b44e66310e66cde64c10ea60` (the same commit as `packages/chrome`).

## Changes from the source

- `package.json` is private, named `@liminal-hq/plugin-window-tearoff` as in Waypoint, and gains a `typecheck` script; the registry fields and licence files it listed are dropped.
- The `autogenerated` and `schemas` permission folders, `node_modules` and `dist-js` are not copied; Tauri regenerates them and `.gitignore` keeps them out.
- `api-iife.js` is rebuilt here by `bun run build:plugins` and committed, so a plain `cargo build` works; `bun run check:bundles` fails when it is stale.
- Nothing in the Rust or guest-js sources changed. The plugin stays generic: it names no part of the studio, which `bun run check:boundaries` enforces.

## Why a copy

The plugin is not published. It lives in Waypoint and is meant to move to the shared plugins workspace; when it is released there, delete this copy and depend on the release. It links the sibling crate `crates/wayland-toplevel-drag` by path (see that crate's `PROVENANCE.md`).
