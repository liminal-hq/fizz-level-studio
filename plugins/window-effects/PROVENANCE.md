# Provenance

This plugin is a copy of `plugins/window-effects` from [liminal-hq/waypoint](https://github.com/liminal-hq/waypoint), taken at commit `a3c9894728da69a9b44e66310e66cde64c10ea60` (the same commit as `packages/chrome`).

## Changes from the source

- `package.json` is private, named `@liminal-hq/plugin-window-effects` as in Waypoint, and gains a `typecheck` script; the registry fields and licence files it listed are dropped.
- The `autogenerated` and `schemas` permission folders, `node_modules` and `dist-js` are not copied; Tauri regenerates them and `.gitignore` keeps them out.
- `api-iife.js` is rebuilt here by `bun run build:plugins` and committed, so a plain `cargo build` works; `bun run check:bundles` fails when it is stale.
- Nothing in the Rust or guest-js sources changed.

## How the studio uses it

Only the status command is open to pages (`capabilities/appearance.json`). Applying an effect is the app's alone, and the studio does not apply any yet.

## Why a copy

The plugin is not published. When it is released from the shared plugins workspace, delete this copy and depend on the release.
